# v118 渡河码头 / THE RIVER FERRY

## 叙事与入口

灵车出了院门，桥却在神死的那夜断了。三个旧房间的东西要靠一位无名摆渡人送过去。v117 的三类车、三种时辰与三项末车裁定集齐后开放；还有赶车人未签收或 v117 pending 时先等它结束。

新增 `ferry-landing`（渡河码头）、`river-crossing`（两岸之间）、`hearing-of-the-last-bank`（末岸听证会），274 → 277 场景，缓存 `v=118`。独立键 `goddead_v118_river_ferry`，只读 v117。

## 渡河规则

船夫与船同岸，负责看守这一岸。点船所在岸的同行者选上船，再点划船；也可独自划回。船夫离开的那岸，不能有规则中列出的冲突双方。错误航程不执行，明确说出无人看守的哪一岸、哪两件东西发生冲突；不扣进度。所有同行者与船夫都抵达右岸才可交货。

| 航法 | 同行者 | 载客上限（不算船夫） | 无人看守时冲突 | 最短趟数 |
| --- | ---: | ---: | --- | ---: |
| 一席小舟 `skiff` | 3 | 1 | 0–1、1–2 | 7 |
| 双桨渡船 `rowing` | 5 | 2 | 0–1、1–2、2–3、3–4 | 7 |
| 无灯夜渡 `night` | 6 | 2 | 0 与其余五件均冲突 | 9 |

三份托运：遗物科（噬名兽 / 遗骨 / 圣盐 / 祷告 / 铜铃 / 白花）→ `reliquary`；投递所（灯蛾 / 空信 / 封蜡 / 邮戳 / 旧地址 / 信封）→ `deadletter`；值夜室（梦影 / 夜簿 / 钟油 / 灯芯 / 火柴 / 围巾）→ `watch`。航法决定使用前几件和冲突图，清单在页面逐项显示。九种航程，每一种都可重复；三份托运、三种航法覆盖就能听证，最短三次交货。

## 操作与存档

两岸明确标为此岸 / 彼岸，同行者按钮标示姓名、船边 / 对岸和选中状态。船位、已划趟数、载客上限和每条冲突都常驻。支持原生点击、触控、Enter / Space；已选角色高亮、岸边看守说明与文字状态共同表达规则。

草稿保存托运 ID、航法 ID 和每趟所载乘客的位掩码序列。从起点逐趟重放验证：人数、所在岸、冲突、空船和船位都检查，非法处截断，最多 99 趟。船位 / 两岸分配 / 趟数由合法历史派生，不信任独立存储的结算标记。刷新恢复合法航程；撤回上一趟、全部回到此岸，换航法或托运会复原。选中的乘客只在内存里，刷新后重新选。

交货前再次检查全部到彼岸；finish pending 也必须匹配已走完的草稿。到达旧房间才记一次交货，摆渡人签收后回码头。首次输入锁定 pending，重复抵达幂等；离开反馈源取消计时但仍保留可恢复 pending。所有新输入走 `isTrusted` 助手。

## 听证与整合

三项裁定：让两岸都有人 → `threshold`；给神留一个船位 → `remembrance`；让河继续流 → `unending-gallery`。三项可重复，收进九次交货 + 三项裁定图鉴。窄桥覆盖基础主线早期守卫与治理 / 画廊守卫，仅允许本章合法交货、未签收摆渡人和裁定目的地。

目录、痕迹室记忆、图鉴折叠、全部遗忘和「下一步」接续 v117；正在等待签收的摆渡人优先给出房间入口。源 PNG 存 `design-references/`，运行时 WebP 存 `assets/`，三张画与提示词另记 `V118ImagePrompts.md`。

## 验收
