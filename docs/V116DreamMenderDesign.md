## 1. 从 v115 接过来

v115 把被子都盖好了，死人睡着了，可他们的梦从缝上裂开了：门外那人梦见自己一直站在门槛上，值夜人梦见灯灭了找不到火柴，注销员梦见划掉的名字从纸上爬出来。缝梦铺只在夜里开门，把每一场梦绷在架子上缝。

> 缝梦铺只在夜里开门。墙上挂满彩线，桌上三只绣绷，各绷着一块裂开的梦。

## 2. 新交互：缝梦（连线填满）

- 绷梦架是俯视的方形木绣架，5×5 的格子铺在亚麻布上（按原画实测），格子都是原生按钮；布上散着几对同色的线结（红、蓝、金、绿、白）。
- 点一个线结起针；点挨着针头的空格往前缝，缝到同色的另一个线结这股线就连上了；点线上的格子退回到那里；再点线结会从那里重新起针（`dmStep` 纯函数）。别的线结、别的线占着的格子都缝不进去（线不能交叉）。
- 每股线用 SVG 折线画出，缝过的格子带一层淡色；所有线都连上并且整块布缝满（`dmSolved`）才能“收针”。线只放在内存里：换线、换梦、“全部拆掉”都会清空，收针在途时锁定。
- 九场梦由脚本生成：先在 5×5 上随机走一条经过每一格的路，再切成 3 / 4 / 5 段，段的两头就是线结（同色线结不相邻）；用模块自己的缝线规则回溯验证，每一场都只有一种缝法。

## 3. 三场梦 × 三种线

| dream | 梦 | 送回 | 缝梦人 |
| --- | --- | --- | --- |
| `threshold-dream` | 门外那人的梦 | `threshold` | 门槛缝梦人 |
| `watch-dream` | 值夜人的梦 | `watch` | 值夜室缝梦人 |
| `cancellation-dream` | 注销员的梦 | `cancellation` | 注销科缝梦人 |

| method | 线 | 线结 |
| --- | --- | --- |
| `three` | 三股线 | 红、蓝、金 |
| `four` | 四股线 | 红、蓝、金、绿 |
| `five` | 五股线 | 红、蓝、金、绿、白 |

收集键 `dream:method`，3×3 = 9。收针后梦送回那个房间，出现“缝梦签收”，点缝梦人回缝梦铺；该房间多一段随最近那种线变化的记忆。

## 5. 数据与边界

- 独立键 `goddead_v116_dream_mending`，version 116，十一字段：version、visited{shop, frame, court}、draft{dream, method}、mends、courtOutcomes、mendRuns、courtRuns、latestMethodByDream、lastOutcome、activeMender{mend}、pending。
- pending 七类（entry / dream / finish / abandon / mender-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v115 开庭条件满足且三项裁定全收集；v115 有在途的被褥或未签收的收被人时入口禁用。
- 前缀 `dm-`；格子用 `dm-knot`，避开图鉴格子 `dm-cell`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`dreamMendingBridgeAllows` 接入治理守卫与画廊守卫。
