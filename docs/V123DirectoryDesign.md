# v123 房间目录与旧支线滚动

## 目标与边界

让长篇回访更容易找路：原目录 278 个链接分区域折叠，支持房间名 / 编号 / 英文路径搜索。保留全部原链接对象、ID、href、别名与各章 hidden / locked / aria-hidden 门槛，280 场景不增减；缓存 v123。沿用原目录门图，新增视觉直接用 HTML / CSS。

旧 v72 / v73 的两条通用 `.scene-branch { overflow: hidden }` 删除，恢复场景系统原本的纵向滚动；插图框本身的裁切不动。桌面和手机要靠普通滚轮实际到达下方按钮。

## 目录合同

- 八区域：主线房间、门厅与副楼、终局与旧事、事实与责任、见证与手作、清晨工坊·上、清晨工坊·下、清晨回访。主线按固定 hash 白名单归类；其余沿原编号范围归类，v101–v104 十二个无编号入口单列清晨工坊·上。区域内保持原相对顺序。
- 初始化时将原链接移入原生 details / summary，不复制或重写门槛。只搜当下可用的链接；不可用项不计数、不呈现搜索结果，空区域隐藏。
- 名称检索同时读原目录标签、场景 data-title、英文 hash 与 kicker；Unicode NFKC、大小写与空白规范化，多词 AND 匹配，不用正则执行用户输入。用独立 data 属性过滤显示，不写各章拥有的 hidden / locked。
- 默认展开主线和当前区域；有查询时展开匹配区域，清除后恢复查询之前的折叠。展开全部 / 收起全部在搜索时禁用。查询及折叠只在本次页面会话，不写任何游戏 / 偏好存档。
- 更新显示 / 可用入口计数与空结果提示；当前房间标 aria-current。观察原链接的门槛变化，打开的目录同步更新，关闭时延迟到下次打开。

## 输入与焦点

目录为 modal dialog：关闭时 inert，打开时场景舞台 inert，Tab / Shift+Tab 限于实际显示且展开的目录控件；Escape 或遮罩 / 关闭按钮关闭并归还目录触发器焦点。维持先聚焦关闭按钮，避免手机自动弹输入键盘。

搜索框 Enter 在唯一结果时沿原 hash 导航；多结果时聚焦首个结果，零结果留在输入框。组合输入不触发 Enter 导航。搜索输入和打开目录时跳过原键盘彩蛋，避免搜索 goddead 写入 awake 或触发神迹。点击原链接沿既有 hash 路由、门禁与场景焦点流程。

新独立静态 `directory.js` 只暴露一个 GoddeadDirectory 入口，包含纯分组 / 匹配规则与原生 DOM 适配；在主脚本前加载。原脚本仅负责连接当前场景与正常导航，不新增存储键、章节状态或第二套路由。

## 验收计划

独立比较 278 入口的分组 / 多种可见档 / Unicode 与多词检索，检查原节点 / 属性保留、隐藏变化、折叠快照、焦点边界、无结果 / 唯一 / 多结果 Enter。全站及旧章测试继续通过，新增静态依赖 / 所有引用与敏感标记检查。

Chrome 桌面 / 375px，用真实输入验证空档目录、已到访早期房间、较长完成档、中文 / 编号 / 英文 / 无结果 / goddead、清除恢复、折叠、Tab 循环 / Esc、点击准确落点、刷新旧草稿与在途菜单竞争。普通滚轮验证代表性旧支线 / 新回访下方操作可达，图片自己的 overflow 仍保留。备份 / 恢复浏览器原档；推送 main 后检查 Pages、公开 HTML / CSS / JS / directory.js 的字节及首页 / 目录。

## 本地结果

合同已实现，30,878 全站断言与旧章 65/65 通过。实机修正首焦点所用 visibility 过渡；保留滑入动画，以 inert 管理关闭状态。Chromium 折叠 details 中链接仍可能有布局盒，Tab 额外检查区域 open；在途换场时中止背景标题的可靠聚焦重试，防止关闭目录后再抢焦点。375px 搜索 / 关闭 / 清除按钮均至少 44px，无横溢。详细结果及发布证据见 [v123-browser-qa.md](../design-qa-evidence/v123-browser-qa.md)。
