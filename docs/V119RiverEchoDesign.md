# v119 河岸回声 / ECHOES FROM THE OTHER BANK

## 回到旧房间

v118 的三项末岸裁定集齐、没有在途渡货或摆渡人时，痕迹室出现「回访回声档案室」。旧三只听筒、v54 迫近 / 断线听筒、所有旧章签收保持原行为和背景；在原房间下方增加河岸回声窗口。回访入口使用本章窄桥抵达 `echo`，不替旧 v29 写到访或选择。没有合法旧声音时，提示玩家先拿起上方旧听筒。

新场景只有 `river-echo-well`（河岸听井），277 → 278，缓存 `v=119`。读当前 v29 `lastChoice.echo` 和 v118 `lastOutcome`，进入听井时捕获声音和裁定；之后即使离开改了旧选择，当前回应仍按已捕获的五拍继续。完成一份即可算本回访完成；九种记录是可选收集。

## 五拍回应

| 旧声音 | 五拍来声 |
| --- | --- |
| 门外敲声 `knock` | 敲、敲、步、铃、敲 |
| 自己脚步 `steps` | 步、敲、步、步、铃 |
| 03:17 的铃 `bell` | 铃、步、敲、铃、铃 |

| 最近末岸裁定 | 回应规则 |
| --- | --- |
| 让两岸都有人 `both-banks-inhabited` | 每拍换一种声音：敲 → 步 → 铃 → 敲 |
| 给神留一个船位 `one-seat-kept-for-god` | 敲与步照答，铃的位置留白；「留白」也是一拍 |
| 让河继续流 `river-still-flowing` | 五拍从最后一声倒着答 |

三旧声 × 三裁定 = 九种回应。来声始终有文字谱，四个原生按钮「敲 / 步 / 铃 / 留白」，选择后逐拍写入草稿；不做限时评分。答错保留正确前缀，明确错误拍数，提示回听规则；不落错误答案。可撤回一拍、重答全部。完整正确的五拍后，才能把回应送进听筒，短反馈自动返回旧 `echo`；旧房间出现对应九种之一的不同余韵与一行记忆。

「再听一遍」按序亮起五格并调用现有音效，视觉谱始终可读，静音与 reduced-motion 都能完成；离场 / 刷新取消播放，不影响已答。按钮同时接受鼠标、触控、Enter / Space。

## 独立状态与恢复

键 `goddead_v119_river_echo`，七个顶层字段：`version`、`visited:{archive,well}`、`draft:{voice,bank,answer}`、`heard`、`runs`、`lastReply`、`pending`。只写本章键；旧 v29 / v54 / v118 只读。白名单、有限整数计数、答拍合法连续前缀、最大五拍；未知与错误历史截断，坏 JSON 保留原串。

三类严格 pending：`revisit`（痕迹室 → echo）、`enter`（echo → 听井）、`reply`（听井 → echo）。来源、目标、逐字反馈、声音 / 裁定、visited 与草稿相互校验；reply 必须等于捕获草稿且确已答完。第一次接受立即写 pending 并锁输入，抵达才结算；源刷新重放，目标重载幂等。离场取消计时并保留 pending；回来继续恢复。回访只临时放行旧 echo，不开放其他旧房间。

目录新听井到访项、痕迹室九格档案、旧房间余韵、全部遗忘和下一步整合。v118 未完成仍显示原进度；完成 v119 一次后显示可选收集提示，后续版本可依此继续早期支线回访。

## 视觉与验收

生成两张原创 1536×1024 插画：旧档案室的临河窗口、河岸听井的三种声物。源 PNG 与 WebP / 提示词入库，文字和操作按钮用 HTML，沿用暗金 / 炭石 / 黄铜 / 晨雾风格。手机按钮至少 44px，高对比活动拍与文字状态并行。

验证九个明确目标谱与全部长度 0–5 输入、错误前缀拒绝、撤回 / 刷新、snapshot 不随上游改变、strict pending 篡改、旧键隔离、旧四热点与压力机制无改动。实机覆盖三个不同声音 / 三裁定代表、错误回答、播放与离场、源刷新 / 重复目标、未解锁深链、375px 布局和控制台。检查规范化前置和实际进度指引，收尾恢复原存档。每版提交推送 main，最后确认公开站缓存和源码 / 图像一致。

## 实装验收结果

2026-10-11，本地验收通过。20,967 条站点断言、65 项 v101–v104 测试；12,285 个独立前缀比较及九条冷恢复生命周期另行统计。Chrome 实走「敲声 / 两岸有人」「脚步 / 神的空位」「铃声 / 河继续流」三条代表路径，三次真实旧听筒选择和两次旧末岸裁定后，逐一完成新五拍并返回。

完整五拍未交付时离开、再次进入仍保留五拍；交付抵达 echo 才清空草稿。交付瞬间刷新源页面，抵达后再刷新只记一次。新谜题阶段旧 v29 / v54 / v118 原串不变；v82–v117 共 36 份前置原串不变。本地原 21 项状态逐项恢复，无测试残留。

回访和回信抵达时焦点落在新窗口标题，并留出 5.5rem 顶栏间距；375px 静音下文字谱、留白与约 70×64px 声音按钮均可操作，无横向溢出。坏 JSON 保留原串、上游未完成时入口隐藏且深链退回痕迹室，无新增 error / warn。具体证据见 [v119-browser-qa.md](../design-qa-evidence/v119-browser-qa.md)。
