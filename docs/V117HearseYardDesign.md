# v117 灵车场 / THE HEARSE YARD

## 叙事与玩法

v116 缝好的梦要随着死人回屋，天亮前院子却堵满了车。玩家在五乘五的俯视院子里挪车：横车只能左右走，竖车只能上下走，途中不能穿过别的车。让发亮的车抵达右墙的院门，再开门放行。

三个场景：`hearse-gate`（灵车场）、`jammed-yard`（挤满的院子）、`hearing-of-the-last-cart`（末车听证会）。场景总数 271 → 274，缓存版本 `v=117`。

## 车与时辰

| 车 | 签收房间 | 赶车人 |
| --- | --- | --- |
| `reliquary-hearse` 遗物科的灵车 | `reliquary` 神圣遗物科 | 遗物科赶车人 |
| `protocol-hearse` 守则厅的篷车 | `protocol` 访客守则 | 守则厅赶车人 |
| `offering-hearse` 焚献炉的灰车 | `offering` 焚献炉 | 焚献炉赶车人 |

三个时辰：天刚亮 / 早上 / 正午。九个固定车阵都可解，最少挪动次数分别为 4–6 / 8–10 / 12–14；一次可以沿车轴挪任意距离。困难来自依赖关系，不单由车的数量决定。点车选中，再点同轴空地挪动；选中时可达空地亮起，再点车取消选择。可把车推回原位，或回门房稍后再来。

挪车位置只存内存，刷新会回到该车该时辰的初始车阵。车、时辰和在途签收保留；换车、换时辰也会复原车阵。目标车到了院门才允许发车，到达旧房间才记一次放行，点击赶车人完成签收、返回门房。图鉴是九次放行与三项裁定，共十二格。

## 实现边界

- 独立键 `goddead_v117_hearse_yard`；只读 v116。十一字段：version、visited、draft、departs、courtOutcomes、departRuns、courtRuns、latestMethodByHearse、lastOutcome、activeDriver、pending。
- 七类严格 pending：entry / hearse / finish / abandon / driver-return / court-entry / verdict。反馈、来源、落点和内容重建后逐字段匹配；首次操作锁定，到达才结算，重复到达幂等，离开取消计时但保留未签收记录。
- 所有按钮经 `isTrusted` 点击助手，支持鼠标、触控、原生 Enter/Space。车身为装饰 span，点击落在原生格子按钮；位置与颜色之外还有轮廓、选中边框、文字与 ARIA 标签。
- 桥接接入治理与画廊守卫；未解锁深链回痕迹室，院子要有草稿才可访问。痕迹室「下一步」接续 v116，目录保留首次到访记录，遗忘清除本章状态。
- 三张场景图使用内置 imagegen 生成，源 PNG 在 `design-references/`，运行时 WebP 在 `assets/`；提示词、哈希与棋盘定位见 `V117ImagePrompts.md`。
