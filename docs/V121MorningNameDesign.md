## 六签三称

六枚名签中恰有一枚比其余五枚偏重或偏轻，起初十二种可能。每枚名签点击循环「桌上 → 左盘 → 右盘 → 桌上」；两盘必须各放同样数量、1–3 枚才可称。记录左重 / 平衡 / 右重，每案最多三次，支持撤回最后一称、清空本案并重称、每步自动保存，静音和键盘可玩。

真实称量结果由该旧选择的固定异常签计算；候选由历史逐次排除，只有留下唯一签及轻重、且玩家认领与记录吻合，才能交回旧称量室。不能凭猜测或未经称量交付。可选「借一套称法」依次称 ①②③ / ④⑤⑥、①④ / ③⑥、②⑤ / ③⑥；这组三称能区分所有十二种情况。玩家也可以自行安排称法。

## 状态和抵达

独立 goddead_v121_morning_name 七顶层字段：version、visited:{room,desk}、draft:{confession,pans,history,claim}、reconciled、reviewRuns、lastReview、pending。pans 六项严格 0/1/2 整数域；history 最多三条恰好 {pans,result}，两盘有效且结果须与捕获案件实际相符，逐项重放，只保留首段有效前缀；坏当前摆盘回空盘；claim 白名单为签号:heavy / light。坏 JSON 原串只读保留。

三类 pending 严格键形状及逐字反馈：revisit remembrance → confession；enter confession → morning-name-balance，须匹配捕获旧选择及 room 到访；reconcile desk → confession，须 desk 到访、记录唯一且认领相符。抵达旧室才追加余韵 / 次数、清空草稿；源刷新重放、目标刷新幂等，上游忙时保留待办。重复案件只增加次数，不重复图鉴。

完成一案即可推进，三种旧选择余韵为可选收集。目录只显示本章实际到访的桌；已完成空桌仍能返回旧室。下一步优先本章 pending / 草稿；全部遗忘清状态、计时器、焦点及面板，旧房间自己的行为继续由旧模块负责。
