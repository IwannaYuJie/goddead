# v108 借光司 · 设计与实现

日期：2026-10-05。设计、前端与测试：Claude；场景原画：本机 Codex CLI（内置 image generation）。状态：已实装。

## 1. 从 v107 接过来

v107 把今天的报纸印成了彩色，可三间旧屋太暗，报纸送进去也没人读得了：无主投递所的信格、神名注销科的名册、访客守则的布告板。借光司专门把外面的光借进暗屋里。

> 借光司只有一扇高窗，光柱里飘着灰。长桌上三只黑盒子一样的房间模型，屋顶上立满了小铜镜。

## 2. 新交互：镜面折光

- 掀开模型的屋顶就是一块 5×5 的石板地（俯视原画，铜线方格按像素实测对齐）。格子上有可翻转的小铜镜和挡光的石柱。
- 25 个格子都是原生按钮；镜子格点一下在“/”和“\”之间翻转（`aria-label` 读出行列与朝向），空地与石柱不能点。
- 光从一侧射入，遇“/”或“\”折 90°，遇石柱被吸收，最多走 80 步（`lbTrace` 纯函数）。光路用 SVG 折线实时画出，入射点是一枚光斑，底边是那间屋唯一的窗；光照进窗时整块地板变亮，状态行报“光拐了 n 次，照进窗了”。
- 只有光照进窗才能“开窗”；镜子朝向只放在内存里：换屋、换光、点“把镜子转回去”都会复原初始朝向，光在途时镜子锁定。
- 测试穷举每间屋每种光的全部镜面组合（2^6–2^8），确认初始都照不进窗、且最少要翻 2–4 面镜子。

## 5. 数据与边界

- 独立键 `goddead_v108_borrowed_daylight`，version 108，十一字段：version、visited{office, floor, court}、draft{model, method}、beams、courtOutcomes、beamRuns、courtRuns、latestMethodByModel、lastOutcome、activeLamplighter{beam}、pending。
- pending 七类（entry / model / shine / abandon / lamplighter-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v107 开庭条件满足且三项裁定全收集；v107 有在途的墨或未签收的学徒时入口禁用。
- 前缀 `lb-`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`borrowedLightBridgeAllows` 接入治理守卫（神圣遗物科、痕迹室）与画廊守卫。
