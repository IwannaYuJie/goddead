# v97 失重局 · 设计与实现

日期：2026-09-24。设计、前端与测试：Claude；场景原画：本机 Codex（内置 image generation）。状态：已实装。

## 1. 从 v96 接过来

v96 把死者的最后一口气还了回去。可神死以后，东西都轻了一点：回声、脉搏、忏悔，这三样早期支线里的东西丢了分量，浮在绒垫上方。

> 失重局的门比看上去轻，一推就开。架子上三只玻璃罩，里面的东西都浮着。

签收处是守则第五条提到的三条老支线：回声档案室、血管维修井、忏悔称量室。它们受 v29 支线守卫保护（没去过就落回走廊），v97 的桥接只在合法称单在途、秤手等签收时放行。

## 2. 新交互：勾选砝码

- 天平室里，图上只剩天平立柱；秤杆和两只秤盘由界面画在立柱轴心上（原图 (767, 340)）。左盘放东西，右盘放砝码。
- 铜砝码是五个可多选的原生按钮（1、2、4、8、16 两，`aria-pressed`）。每加减一块，秤杆立即按差值倾斜（每两 3°，限幅 15°），秤盘始终竖直下垂；两边相等时秤杆发光。
- 秤平了按“落秤”。没平会说明是砝码多了还是不够，并重复该称法的要求。
- 砝码只放在内存里：换称法时留在盘上，换一样东西时清盘，称单在途时锁定。
- `lwPanTotal`（非法或重复砝码一律作废）和 `lwBeamAngle` 是纯函数。

## 3. 三样东西 × 三种称法

| thing | 名称 | 原重 | 送回 | 秤手 |
| --- | --- | --- | --- | --- |
| `lost-echo` | 回声 | 7 两 | `echo` | 回声秤手 |
| `lost-pulse` | 脉搏 | 5 两 | `vein` | 脉搏秤手 |
| `lost-confession` | 忏悔 | 9 两 | `confession` | 忏悔秤手 |

| method | 称法 | 砝码应合计 |
| --- | --- | --- |
| `restore` | 称回原重 | 原重 |
| `double` | 加倍奉还 | 原重 × 2（忏悔要用到 16 两） |
| `fill` | 补足一斤 | 16 − 原重（旧秤一斤十六两） |

收集键 `thing:method`，3×3 = 9。秤平后称单送回那条支线，出现“称单签收”（原重 → 称回多少两，以及结果），点秤手回失重局；该支线多一段随最近称法变化的记忆。

## 4. 法庭

条件：三样东西都称过、三种称法都用过。最短三次。

## 5. 数据与边界

- 独立键 `goddead_v97_lost_weight`，version 97，十一字段：version、visited、draft{thing, method}、weighings、courtOutcomes、weighingRuns、courtRuns、latestMethodByThing、lastOutcome、activeWeigher{weighing}、pending。
- pending 七类（entry / thing / weigh / abandon / weigher-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v96 开庭条件满足且三项裁定全收集，经 `store.memo` 缓存；v96 有在途记录时入口禁用。
- 前缀 `lw-`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`lostWeightBridgeAllows` 接入治理守卫、画廊守卫和 v29 支线守卫。

## 6. 美术

三张 1536×1024 由本机 Codex CLI 生成：度量衡局架子上三只玻璃罩（海螺 / 发红光的心形小瓶 / 封蜡的信，都浮着）、卸掉秤杆的天平立柱（左右留空给界面画秤杆）、穹顶吊着水平大天平的法庭（羽毛 / 一摞砝码 / 空秤盘）。提示词与哈希见 `docs/V97ImagePrompts.md`。
