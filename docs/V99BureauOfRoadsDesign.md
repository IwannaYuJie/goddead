# v99 引路司 · 设计与实现

日期：2026-09-25。设计、前端与测试：Claude；场景原画：本机 Codex（内置 image generation）。状态：已实装。

## 1. 从 v98 接过来

v98 把灯挂到了门口，可死者还是找不到路。引路司收了三张旧房间的路图，每张只画了一半。

> 引路司的门朝里开，门后是一张长桌。桌上摊着三张路图，都画了一半。

签收处是门外、访客守则、值夜室——玩家最早走过的三个房间。

## 2. 新交互：旋转路砖

- 铺路台上 3×3 九块路砖是原生按钮，砖面画着直路（I）、弯路（L）或丁字路（T）。点一下，整块砖带动画顺时针转 90°。
- 左边中间是发光的入口；右边上 / 中 / 下是三个出口，当前去处的出口会描金，接通时亮起。
- 从入口能走到的砖实时亮起，玩家一眼能看出路断在哪里。接通后“落定”；没接通会提示。可“复位”回到路图上画的样子。
- 每块砖转了几次只放在内存里：换去处时保持，换一张路图时复位，路条在途时锁定。
- `rdRotate`、`rdReach`（从入口广度优先）和 `rdConnected` 是纯函数。三张路图是用脚本搜出来的：三个出口都可达、初始都不通、最少点击 3–8 次；测试里用穷举再次验证。

## 3. 三张路图 × 三个去处

| road | 名称 | 砖型（行优先） | 送回 | 引路人 |
| --- | --- | --- | --- | --- |
| `threshold-road` | 门外的来路 | L I L / L T T / T L L | `threshold` | 门外引路人 |
| `protocol-road` | 守则背后的小路 | I I I / T L T / T L I | `protocol` | 守则引路人 |
| `watch-road` | 值夜室的后巷 | L L T / T L L / T I T | `watch` | 值夜引路人 |

| method | 去处 | 出口 |
| --- | --- | --- |
| `rise` | 升上去 | 右上角那块的北口 |
| `forth` | 走出去 | 右边正中那块的东口 |
| `sink` | 沉下去 | 右下角那块的南口 |

收集键 `road:method`，3×3 = 9。落定后路条送回那个房间，出现“路条签收”，点引路人回引路司；该房间多一段随最近去处变化的记忆。

## 5. 数据与边界

- 独立键 `goddead_v99_roads_for_the_dead`，version 99，十一字段：version、visited、draft{road, method}、routes、courtOutcomes、routeRuns、courtRuns、latestMethodByRoad、lastOutcome、activeLeader{route}、pending。
- pending 七类（entry / road / pave / abandon / leader-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v98 开庭条件满足且三项裁定全收集，经 `store.memo` 缓存；v98 有在途记录时入口禁用。
- 前缀 `rd-`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`deadRoadsBridgeAllows` 接入治理守卫与画廊守卫。

## 6. 美术

三张 1536×1024 由本机 Codex CLI 生成：长桌上三张画着九格石路的羊皮路图（压着门环 / 布告钉 / 怀表）、俯视的黑石铺路台（正中方形凹槽，左侧发光拱门、右侧三个暗洞，路砖由界面画进凹槽）、众路汇聚的圆厅（钥匙 / 里程石 / 皮靴）。提示词与哈希见 `docs/V99ImagePrompts.md`。
