## 2. 新交互：滑块拼版

- 拼版台是 3×3 的九格方盘，八块碎版加一个空位（拼齐时空位在右下角）。九格都是原生按钮：点一块挨着空位的碎版，它就推进空位；不挨着的提示“推不动”。
- 碎块的画面从一张“三块方形木刻并排”的拼版原图（`assets/v106-type-plates.webp`）按格裁出；已归位的碎块描金边。右边一直显示这块版原来的样子做参照。
- 状态行显示推了几次、几块归位；“摆回原样”回到刚摔下来的样子，换摔法会重新打乱。拼齐才能锁版。
- 打乱方式：从拼好的版出发，用“版 + 摔法”做种子随机推若干步、不走回头路，保证一定可解，同一局每次一样。
- `tsNeighbors`、`tsSlide`、`tsSolved`、`tsScramble`、`tsPieceBackground` 是纯函数；测试用广度优先搜索逐一验证九种组合都可解。

## 3. 三块版 × 三种摔法

| plate | 名称 | 送回 | 排字工 |
| --- | --- | --- | --- |
| `door-plate` | 门的木刻版 | `threshold` | 门外排字工 |
| `clock-plate` | 钟的木刻版 | `watch` | 值夜排字工 |
| `furnace-plate` | 炉的木刻版 | `offering` | 焚献排字工 |

| method | 摔法 | 打乱步数 |
| --- | --- | --- |
| `loose` | 只松了几块 | 8 |
| `scattered` | 散了一地 | 16 |
| `shattered` | 摔得粉碎 | 28 |

收集键 `plate:method`，3×3 = 9。锁版后头版送到那个房间，出现“头版签收”，点排字工回印刷所；该房间多一段随最近摔法变化的记忆。

## 5. 数据与边界

- 独立键 `goddead_v106_typesetting_today`，version 106，十一字段：version、visited{press, stone, court}、draft{plate, method}、prints、courtOutcomes、printRuns、courtRuns、latestMethodByPlate、lastOutcome、activeSetter{print}、pending。
- pending 七类（entry / plate / lockup / abandon / setter-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v105 开庭条件满足且三项裁定全收集；v105 有在途早餐或未签收的跑堂时入口禁用。
- 前缀 `ts-`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`todayPressBridgeAllows` 接入治理守卫与画廊守卫。
