# v111 归位司 · 设计与实现

日期：2026-10-06。设计、前端与测试：Claude；场景原画：本机 Codex CLI（内置 image generation）。状态：已实装。

## 1. 从 v110 接过来

v110 把三间屋的地扫干净了，可扫的时候挪开的家具还停在屋子中间：神圣遗物科的两只矮柜、余响交换台的两条长凳、走廊的两把长椅。地上留着它们多年压出来的印子，而且不止一层——昨天的、去年的、神还在时的。

> 归位司的墙上钉满了旧平面图。长桌上三件小家具模型，各站在一圈粉笔印子里。

## 2. 新交互：推回印子

- 那间屋是俯视的 5×5 木地板（原画铜线按像素实测对齐），有墙角和柱子挡路；两件家具是深色木箱，选中的那层印子画成浅色虚线框，推的人是一盏小灯。
- 25 格都是原生按钮。点挨着你的空格就走过去；挨着家具就把它沿同一方向推一格——后面是墙、另一件家具或地板边就推不动（`pbStep` 纯函数）。只能推不能拉。
- 家具站进印子就发亮，两件都站进去时状态行报“两件家具都回到了昨天的印子里”，才能“归位”。可以“退一步”（记录每一步的历史）或“全部挪回去重来”。位置只放在内存里：换一层印子、换屋都会把家具挪回扫地时的位置，归位在途时地板锁定。
- `pbMinMoves` 广搜最少步数（走和推各算一步）；测试确认 9 种组合都要 11–18 步，并用测试自己的广搜规划出真实点击序列让模块走通。

## 5. 数据与边界

- 独立键 `goddead_v111_putting_back`，version 111，十一字段：version、visited{office, floor, court}、draft{room, method}、places、courtOutcomes、placeRuns、courtRuns、latestMethodByRoom、lastOutcome、activeMover{place}、pending。
- pending 七类（entry / room / finish / abandon / mover-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v110 开庭条件满足且三项裁定全收集；v110 有在途的地或未签收的扫地人时入口禁用。
- 前缀 `pb-`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`puttingBackBridgeAllows` 接入治理守卫（神圣遗物科、痕迹室）与画廊守卫。
