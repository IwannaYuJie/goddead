# v120 清晨脉搏 / THE FIRST MORNING PULSE

## 旧井里的天亮

完成 v119 任一份河岸回应后，痕迹室出现「回访血管维修井」。入口仍要求 v119 的真实上游解锁；v119 草稿 / pending、渡河或赶车签收在途时先完成原任务，不强迫收齐九种余韵。

旧 `vein` 的 v29 顺流 / 逆流 / 隔离三阀、v30 泵房、v53 信念、v54 背景切换 / 迫近 / 过压表全部保留。新窄桥只放行 `vein`，不写旧到访或选择。旧房间下方增加「井底第一次有了天光」面板；没有实际合法旧阀门选择时提示先操作上方旧阀。

唯一新场景 `dawn-pulse-manifold`（晨脉接管台），278 → 279，缓存 `v=120`。进入时捕获 `getBranches().lastChoice.vein`：顺流 `down`、逆流 `up`、隔离 `isolate`；旧选择决定九管的形状、初始朝向、入口与出口。之后改变旧阀门不改本次草稿。修好一条就完成回访，三种脉搏余韵是可选收集。

## 九管接晨光

3×3 接管台，每段都是两口铜管；横直管有两种朝向，弯管有四种。每点一次顺时针转一格，接上的管路泛亮，向外或缺少相邻接口的口标漏光。入口与出口明确画出并以文字说明；让入口接到出口、九段全在同一路径上，且没有漏口，才可「让第一下脉搏回到井里」。不计时，无需声音。

格号 0–8 为上到下、左到右；方向 0/1/2/3 为上/右/下/左。直管基准为右+左，弯管基准为上+右，顺时针旋转。设计路径用来独立生成 / 核对形状和目标，不向玩家暴露答案。

| 旧阀 | 入口 → 出口 | 设计路线 |
| --- | --- | --- |
| 顺流 | 左上格左口 → 右下格右口 | 0,1,2,5,4,3,6,7,8 |
| 逆流 | 左下格左口 → 右上格右口 | 6,7,8,5,4,3,0,1,2 |
| 隔离 | 右上格上口 → 左下格下口 | 2,5,8,7,4,1,0,3,6 |

三局均含五直管 / 四弯管，各有 8,192 种物理朝向，独立枚举核对唯一完整管路。朝向与初始打乱写明在源码表中；验收比较全部 24,576 种朝向的连通、漏光、出口、完成状态，不用同一生产算法生成预期。

可退回最近一步、恢复这份草稿的初始管路、稍后再接；朝向逐步保存，刷新接续，撤销最多保留最近 64 次旋转。按钮为原生键盘 / 触控控件，标签读出格号、管型、接口方向与当前亮起状态；操作反馈给出接通段数和首个漏口位置。SVG 只画管路，环境插画不承担规则。

## 状态和转场

独立键 `goddead_v120_dawn_pulse`，七顶层字段：`version`、`visited:{well,work}`、`draft:{valve,turns,undo}`、`repairs`、`repairRuns`、`lastRepair`、`pending`。每管朝向严格限定整数域；缺损朝向回到该局初始管路，撤销只保留合法格号的连续末段且最长 64 项；未知阀与历史丢弃，计数非负有限封顶 9999，坏 JSON 保留原串直到真实输入。

三类严格 pending：`revisit`（痕迹室 → vein）、`enter`（vein → 接管台）、`repair`（接管台 → vein）。来源 / 目标 / 逐字反馈 / 捕获阀 / 到访与草稿相互校验；repair 必须对应无漏且九段全通的草稿。接受时立刻落盘并锁输入，源刷新重放，目标抵达仅结算一次，返回旧井后才清草稿。上游忙时不结算，pending 保留。痕迹室继续入口可带回 pending 的来源或已有工作草稿。

修好后旧井留下三种之一的不同清晨文字，痕迹室有三格收集；目录、全部遗忘与下一步整合。旧 v29 / v30 / v53 / v54 / v119 只读；真实旧阀选择自身的旧记录仍照常写入。

## 2026-10-11 实装验收

三局独立枚举全部 24,576 朝向，与生产连通 / 漏口 / 出口 / 完成状态逐项相等，均唯一解、最少 14 转。21,189 站点断言、65 旧章测试通过。Chrome 实际选择三旧阀，旧目标依次走廊 / 守则 / 逆流泵房；三条新管路全部接通并返回三种不同余韵。

第一 / 第二局途中刷新继续，第三局完整未交付离场恢复、交付瞬间刷新和目标重载只记一次。375px 静音操作正常，铜管格约 98×98px、无横溢；回访焦点为 dp-well-title。缺损数组被拒绝，坏 JSON 原串保留，未完成上游深链回痕迹室；v119 有一拍未完成草稿时，旧回应优先且 v120 入口禁用。已交付接管台的目录空态仍可回旧阀门。

三局新回访前后分别核对旧 v29 / v30 / v53 / v54 / v119 原串相等，38 份上游原串相等，原本地 21 项逐项恢复、无测试键残留，无新增 error / warn。见 [v120-browser-qa.md](../design-qa-evidence/v120-browser-qa.md)。
