# v96 屏息当铺 · 设计与实现

日期：2026-09-24。设计、前端与测试：Claude；场景原画：本机 Codex（内置 image generation）。状态：已实装。

## 1. 从 v95 接过来

v95 的听证会把“一小时”借给了死者。借到时间的人拿来抵押的，是他们最后一口气。

> 当铺的门帘自己掀开了。柜台上三只玻璃瓶，瓶里的气还在慢慢转。

三口气取自三个 v93 用过、v94/v95 没再去过的旧房间：走廊、余响交换台、无主投递所。

## 2. 新交互：按住再松手

- 风箱柜台上，图里的风箱是原生按钮：按住（鼠标 / 触屏，或聚焦后按住空格 / 回车）开始压气，松手送出。
- 右边的竖直压力表是 `role="meter"`：金色区间是目标，液柱按住的时间匀速上升，3.6 秒压满、压满即止；指针进了区间会亮一下。
- 判定只看松手那一刻的压力：落在目标 ±8% 之内算对；120ms 以内的点按不算。松早 / 松晚会分别说明，并报出压到了多少、区间是多少，可以一直重来。
- 按下的时刻只放在内存里，不写存档；指针取消、失焦、丢失捕获都会中止这一次按压；键盘长按的自动重复被忽略。
- 指针、按键事件都要求 `isTrusted`；`hbLevelFromMs` 与 `judgeBreathHold` 是纯函数。

## 3. 三口气 × 三种赎法

| breath | 名称 | 长度 | 送回 | 估价师 |
| --- | --- | --- | --- | --- |
| `corridor-breath` | 走廊里憋住的一口气 | 60% | `corridor` | 走廊估价师 |
| `switchboard-breath` | 听筒里的一声喘 | 30% | `switchboard` | 接线估价师 |
| `deadletter-breath` | 死信里封着的叹息 | 80% | `deadletter` | 投递估价师 |

| method | 赎法 | 目标压力 |
| --- | --- | --- |
| `return` | 原样还给他 | 这口气的长度 |
| `half` | 只还一半 | 长度的一半 |
| `hold` | 替他屏住 | 压满（100%） |

收集键 `breath:method`，3×3 = 9。压对后那口气送回原来的房间，出现“赎票签收”（写明这口气多长、还回去多少，以及结果），点估价师回当铺；该房间多一段随最近赎法变化的记忆。换一口气时赎法重置为“原样还给他”。

## 4. 法庭

条件：三口气都赎过、三种赎法都用过。最短三次。

| action | 裁定 | 抵达 |
| --- | --- | --- |
| `let-the-dead-exhale` | 让死者呼出来 | `switchboard` |
| `keep-one-breath-in-escrow` | 留一口气作押 | `remembrance` |
| `let-the-living-hold-it` | 让活人替他们屏住 | `unending-gallery` |

## 5. 数据与边界

- 独立键 `goddead_v96_held_breath`，version 96，十一字段：version、visited、draft{breath, method}、redemptions、courtOutcomes、redemptionRuns、courtRuns、latestMethodByBreath、lastOutcome、activeAppraiser{redemption}、pending。
- pending 七类（entry / breath / redeem / abandon / appraiser-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v95 开庭条件满足且三项裁定全收集，经 `store.memo` 缓存；v95 有在途记录时入口禁用。
- 前缀 `hb-`；按钮只接受真实点击；存档内容只以 textContent 渲染；`heldBreathBridgeAllows` 接入治理守卫与无终局画廊守卫。

## 6. 美术

三张 1536×1024 由本机 Codex CLI 生成：铜栅栏后柜台上三只封蜡玻璃瓶（气的大小对应三口气的长短）、木架上的皮革铜风箱接着玻璃瓶（右侧留空放压力表）、后墙是管风琴的法庭（听筒 / 打开的玻璃瓶 / 刚吹灭的蜡烛）。提示词与哈希见 `docs/V96ImagePrompts.md`。

## 7. 验收记录

- 测试：新增 v96 块，含压力换算与判定单测（半程五成、压满即止、区间内外、120ms 点按不算）、锁定、最短三次开庭（分别用指针、空格、回车长按；每次先松早、再松晚都被拒）、合成事件不压风箱、中途松脱不送、换气重置赎法、放回柜台、在途时风箱锁定、pending 生命周期、v95 在途禁用入口、坏档与伪造字段、遗忘重置。
- 浏览器（内置浏览器，v95 全部完成的存档）：痕迹室入口；当铺三个热点对准三只瓶；风箱柜台压力表显示目标区间；真实单击判“松早了：压到 0%”；一次真实按住拖动约两秒松开，落在 52–68% 区间，送回走廊并显示赎票签收与记忆；聚焦风箱后真实空格判“松早了”（键盘接线正常）；375px 宽无横向滚动，风箱标签不折行。浏览器工具无法精确控制按住时长，其余两口气和法庭的完整路径由自动测试覆盖。
