# v51 副楼三债 / THE ANNEX KEPT THREE DEBTS

## 目标

v51 不再增加一条固定长走廊，而是让 v32/v50 副楼的 13 个现有动作形成三条可读、可积累、会反过来改变房间的倾向：

- **见证值**：主动看见、聆听、回望那些原本不该被确认的东西。
- **失号值**：抹去编号、选择空白、把自己交给没有登记的出口。
- **逆行值**：复核、申报、折返，试图让规则自行否定。

三条值不是通关优劣，也不是传统善恶。玩家点什么，副楼就学会用哪一种方式回应。

## 设计依据

这一轮采用恐怖互动游戏里最适合 Goddead 的三种方法：

1. **选择需要产生可预期但不完全可控的后果**：玩家能看懂自己在积累什么，却不能提前知道房间会怎样变形。
2. **观察本身就是风险**：不是每个异常都要立刻处理；确认异常会让异常确认玩家。
3. **声音和画面先给微弱反馈，再开放新路径**：阈值变化必须能被感知，避免隐藏数值毫无提示。

## 债值规则

- 每个既有动作只增加一条债值 `+1`，总上限均为 `9`。
- 13 个动作按 `5 / 4 / 4` 分配；现有反馈、mark、首选锁和 AutoAdvance 全部保留。
- 债值写入一个新的、独立、容错解析的本地状态；不得改写 v32/v33/v35 的既有状态键。
- 进入三间房时，在图像边缘出现一块黄铜压印小牌，显示 `见证 / 失号 / 逆行` 三行刻痕。它是场景内物件，不做全局游戏 HUD。
- 任一债值达到 `3` 时，只解锁对应房间的一次条件异常；阈值不会自动跳转，玩家仍要主动点异常物件。
- 条件异常触发后即时反馈并自动切到既有相邻场景，不增加底部“继续”按钮。

## 三个阈值异常

### 见证 ≥ 3：闭目档案室 / 三只抽屉睁眼

- 使用新源图 `design-references/source-v51-annex-eyelid-witness.png`。
- 只在中央柜下半部让三只原本闭合的黄铜眼睑抽屉微微开启，露出潮湿、苍白、互相不同方向凝视的眼球。
- 新热点必须贴在三只睁开的抽屉上；可见短标签：`让它们看清`。
- 触发反馈：`三只眼睛没有看你。它们在核对你身后站着几个你。`
- 触发后进入 `#unnumbered-vestibule`。

### 失号 ≥ 3：无号前厅 / 第十扇空门

- 使用新源图 `design-references/source-v51-annex-vestibule-tenth.png`。
- 环形九门保持不动，在中央无把手黑门的阴影里显出一圈更窄、更深的第十扇门框；门楣空白，不出现数字或文字。
- 新热点只覆盖新门框内部；可见短标签：`进入未编号的第十门`。
- 触发反馈：`你没有推门。门从你的编号里向内打开。`
- 触发后进入 `#reverse-stairwell`。

### 逆行 ≥ 3：逆向阶井 / 镜中重复阶井

- 使用新源图 `design-references/source-v51-annex-stairwell-double.png`。
- 左上窄黑镜里出现一套与现实楼梯方向相反、透视不可能成立的重复阶井；现实构图和既有四个物件不动。
- 新热点贴在镜中重复阶井上；可见短标签：`走进倒置的阶井`。
- 触发反馈：`镜中的脚先落地，你的脚才想起该抬起来。`
- 触发后进入 `#eyelid-archive`，形成可感知的三房环路。

## 反馈与可访问性

- 债值变化时播放一声很轻的黄铜压印音，并由现有 `aria-live` 读出：`见证留下第一道刻痕` 等。
- 静音时保留视觉刻痕；reduced-motion 下禁用牌面抖动和异常呼吸，只保留立即完成的显现。
- 三个新热点必须支持鼠标、Tab、Enter、Space，触控尺寸不小于 `44×44`。
- 阈值未到时热点必须 `hidden`，不可聚焦，也不可通过直接 hash 或合成点击越权触发。
- 阈值达到时图像与热点原子切换；刷新后恢复，不重复播报解锁。

## QA 门槛

- 13 个旧动作逐一证明只增加预定债值，连点与 rival action 不得重复计数。
- `0 / 2 / 3 / 9 / 坏 JSON / 数组 JSON` 状态矩阵完整验证。
- 三个阈值热点在 `2` 时完全不可达，在 `3` 时原子出现，触发后各自一次自动转场。
- 三条债值互不串写；三种解锁可同时存在并在刷新后恢复。
- 桌面 1440×1024、移动 390×844 各验证三间房：刻痕牌、异变图、热点命中、无溢出、无互盖。
- 每张源图与网页渲染裁切做同帧并排对照，监理逐张目验后才可放行。
