## 1. 从 v114 接过来

v114 把门都锁上了，死人要睡了。三间旧屋的被褥得叠好收进柜子：走廊长椅上守夜人裹过的灰毯子、交换台接线员夜里披的红毛毯、守则厅拆下来当被子盖的旧帷幔。每一包都折成了不同的形状，要正好把柜子塞满。

> 被柜房里架子上全是叠好的布，灯光暖暖的。长桌上三包没叠的被褥，各用绳子捆着。

## 2. 新交互：收被入柜（拼放）

- 叠被处的地板上画着一口柜子（四行高，按柜子形状 4 / 5 / 6 列），柜子里每一格都是原生按钮。
- 下面一排是这一包的五床被子（原生按钮，带 4×4 小样显示当前形状）。点一床拿起来，可以“转一转”“翻个面”；再点柜子里的格子，被子“左上角那一格”落在那里（`lnPlace`：伸出柜子、压到别的被子都会被拒绝并提示）。
- 放进去的被子按颜色区分；点柜子里的被子或再点那床被子都能把它拿出来。五床正好塞满柜子（`lnFull`）才能“合上柜门”。摆法只放在内存里：换柜子、换一包被褥、“全部拿出来”都会清空，合柜在途时锁定。
- 被子一共有六种折法（对折 2 格、三折长条与三折拐角 3 格、四方叠 / 丁字叠 / 曲尺叠 4 格），每包五床合计 16 格；三种柜子也都是 16 格。用回溯穷举挑出三包，在三种柜子里各有 2–24 种塞法。
- 托盘与“转一转 / 翻个面”放在面板最上面，紧贴柜子，桌面上不用来回滚动。

## 5. 数据与边界

- 独立键 `goddead_v115_linen_room`，version 115，十一字段：version、visited{room, floor, court}、draft{bundle, method}、folds、courtOutcomes、foldRuns、courtRuns、latestMethodByBundle、lastOutcome、activeFolder{fold}、pending。
- pending 七类（entry / bundle / finish / abandon / folder-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v114 开庭条件满足且三项裁定全收集；v114 有在途的钥匙或未签收的守锁人时入口禁用。
- 前缀 `ln-`；柜子格子用 `ln-slot`、被子用 `ln-piece`，避开图鉴格子 `ln-cell`；模块内只有一个事件绑定点（真实点击助手）；存档内容只以 textContent 渲染；`linenRoomBridgeAllows` 接入治理守卫与画廊守卫。
