# v107 调墨房 · 设计与实现

日期：2026-10-05。设计、前端与测试：Claude；场景原画：本机 Codex CLI（内置 image generation）。状态：已实装。

## 1. 从 v106 接过来

v106 把今天的头版拼好了，可印报没有墨。三个旧房间各留下一种颜色：走廊尽头那盏灯的暖黄、遗物科圣物箱上磨掉的旧金、交换台铜插头生锈后的铜绿。

> 调墨房里一股胶和矿粉的味道。长桌上三只墨缸，每只前面靠着一张色卡。

## 2. 新交互：滑条调色

- 调色碟下面是三根原生 `input type="range"`：朱砂、藤黄、靛青，各 0–6 份，鼠标拖、触屏拖、方向键都能调；每根滑条读出“藤黄 3 份”。
- 颜色按份数加权平均三种颜料，再按总份数盖过纸色（`mxMix`）。调出的颜色实时画进原画里那只透视的白瓷碟底，右上角是色卡和色差条（`role="meter"`，够近时变金）。
- 状态行实时报“色差 x.x%”。三档精度：差不多就行（≤6%）/ 仔细调（≤3%）/ 分毫不差（≤0.5%）。够近才能“倒进墨槽”。
- 份数只放在内存里：换样色或换精度时洗碟，墨在途时滑条锁定。滑条只认真实的 `input` 事件。
- 测试穷举 343 种份数组合，确认每种样色在每档精度下都有 1–60 种可行解，既能调出来也不至于随便拖拖就过。

## 3. 三种样色 × 三档精度

| ink | 名称 | 配方（朱 / 黄 / 靛） | 送回 | 学徒 |
| --- | --- | --- | --- | --- |
| `corridor-ink` | 走廊的灯色 | 1 / 4 / 0 | `corridor` | 走廊学徒 |
| `reliquary-ink` | 遗物科的旧金 | 2 / 3 / 1 | `reliquary` | 遗物科学徒 |
| `switchboard-ink` | 交换台的铜绿 | 0 / 3 / 3 | `switchboard` | 交换台学徒 |

| method | 精度 | 色差 |
| --- | --- | --- |
| `rough` | 差不多就行 | ≤ 6% |
| `careful` | 仔细调 | ≤ 3% |
| `exact` | 分毫不差 | ≤ 0.5% |

收集键 `ink:method`，3×3 = 9。倒墨后色样送到那个房间，出现“色样签收”，点学徒回调墨房；该房间多一段随最近精度变化的记忆。

## 5. 数据与边界

- 独立键 `goddead_v107_ink_mixing`，version 107，十一字段：version、visited{room, dish, court}、draft{ink, method}、mixes、courtOutcomes、mixRuns、courtRuns、latestMethodByInk、lastOutcome、activeApprentice{mix}、pending。
- pending 七类（entry / ink / pour / abandon / apprentice-return / court-entry / verdict），按 kind 与当前状态重建期望对象，逐字段一致才接受。
- 解锁：v106 开庭条件满足且三项裁定全收集；v106 有在途头版或未签收的排字工时入口禁用。
- 前缀 `mx-`；模块内只有两个事件绑定点（按钮的真实点击助手、滑条的真实 input）；存档内容只以 textContent 渲染；`inkMixingBridgeAllows` 接入治理守卫（神圣遗物科、痕迹室）与画廊守卫。

## 6. 美术

三张 1536×1024 由本机 Codex CLI 生成：颜料作坊长桌上三只墨缸与色卡（灯色 / 旧金 / 铜绿）、空白瓷碟与三只颜料罐（朱砂 / 藤黄 / 靛青）、挂满白幡的听证厅（墨锭砚台 / 空白色卡 / 混色软笔）。调色碟是透视椭圆，碟心约 (430, 545)，界面按此画颜色。提示词与哈希见 `docs/V107ImagePrompts.md`。
